# Spanish educational page and SEO

Write for anyone who wants good results from image or video generators without knowing how to write prompts: an individual who wants photos of themselves in different styles, someone selling a car who needs listing photos, a small seller, a creator, a marketer. Assume no prior prompt knowledge; plain everyday Spanish, technical terms explained in one phrase the first time. Title, summary, category explanation, mode_help, education, customization labels, image alt and SEO should be in natural Spanish. The executable visual prompt and replacement fragments should be English.

Explain (a) what practical content task the template solves, (b) who uses it, (c) what to upload for img2image and how the fictional example fixture illustrates that upload, (d) what the canonical prompt changes and preserves, (e) how to replace the fields, (f) what to verify before commercial use, (g) known model limitations, and (h) variations without unsupported promises.

Require 2–5 personalizable fields whose default `value` literally appears in the canonical prompt; each has 2–6 English examples. Use focused existing category/tags, 1–2 sentence summary, 3–6 suitable tags, meta_title <=60 characters, meta_description <=160 characters, free access unless specified, and deliberate noindex behavior. Image templates: one independently generated gallery image per execution; for img2image a separate input image. Video templates: the video plus a poster frame; for img2video a separate input image. Do not call a fictional specimen a user-submitted real product or imply trademark rights.
