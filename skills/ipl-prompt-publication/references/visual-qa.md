# Mandatory visual QA on real output

Compare the actual generated file with the canonical prompt. A score is not a substitute for hard requirements. Evaluate:

1. **Semantic fidelity:** correct subject, use case, scene and number of outputs; no prompt-card, moodboard, collage or unrelated image unless explicitly requested.
2. **Critical identity/text:** exact brand name, headline, logo lettering, supplied source/product identity, required labels and absence of invented factual claims.
3. **Composition:** aspect, focal point, hierarchy, framing, breathing room, camera/viewpoint where required and crop safety.
4. **Style:** color palette, graphic/photographic treatment, lighting, material realism, clean vector-style edges when asked, no prohibited gradients, shadows or extraneous elements.
5. **Technical visible quality:** readable small typography, plausible anatomy/objects, sharpness, compositional balance, artifacts and text distortions.
6. **Educational demonstration:** the example convincingly represents the result a visitor may expect from the saved prompt. Never display a fundamentally different image as an example.
7. **Reference/image-editing fidelity:** compare against provided source; list any changed branding, geometry or material that should have remained fixed.

**BLOCK / STOP:** wrong required subject; incorrect exact text; missing distinctive element; wrong output type or substantial composition/style mismatch; hallucinated real product claims; severe artifacts; unrelated uploaded file; absent usable file ID. Do not publish, revise prompt after generation or generate another image automatically.

**MINOR:** slight tonal variation or interpretive stylistic difference that doesn't breach any mandatory constraint. Accept with objective note; do not overclaim perfection.

If the user explicitly requested visual review before publication, that request establishes a further user decision after QA. Otherwise follow publication authorization agreed at Intake and avoid redundant approval.
